name: hep-skill-governance
description: 设计或调整 hep-lab 共享开发 Skill 的归属、允许清单、触发范围与投影，或排查跨仓 Skill 重名、缺失和误触发。业务运行 Skill 正文优化交给其所属仓，不用于一般代码审查。
---

区分开发工具上下文与 DSH 运行资产。共享开发方法维护在本工作区 `skills/`；程序开发方法保留程序仓；管理助手方法维护 DSH HOME；业务方法维护所属业务 Harness。只有已经存在的跨仓需求才新增共享包。

1. 查看现有技能目录和 `.hep-lab/sources.json`，确认是否已有公开入口。相同名称不代表相同语义，不通过全目录复制合并。
2. 描述写清具体触发任务和排除项，正文只保留操作方法，详情和脚本放同包。公开合同用链接；不依赖仓库外的相对文件或其他包的私有实现。
3. 共享投影只改允许清单与唯一源包，用工作区工具生成目标。包中不得携带凭据、依赖安装目录或运行状态。
4. 分别检验显式调用、隐式调用、相邻但不应触发的任务，以及一个跨仓任务。核对真实开发工具的发现结果；发现正确不等于模型调用或业务效果通过。
5. 需要证据时记录输入、真实来源及 dirty 状态、实际调用和观察；不要仅凭描述字符串测试声称路由准确率提升。
